# 印鑑アプリ（StampApp）設計書

- 作成日：2026-05-22
- 種別：仕様書（design doc）
- 配布形態：Windows用デスクトップアプリ（単一EXE）

---

## 1. 目的

PDF上に予め描かれた位置指定マーク（◴◰⊗⊠☆）を自動検出し、そのマーク中心に合わせて、アプリ内で生成した円形3分割の印鑑PNGを貼り付けるGUIアプリを作成する。Acrobat製PDFとスキャナでスキャンした画像PDFのどちらにも対応する。

## 2. 機能要件

### 2.1 PDFの取り込み

- 「PDFを開く」ボタンでファイル選択ダイアログを表示
- 単一PDFを開く（複数ファイル一括処理は対象外）
- 開いた直後にバックグラウンドで全ページのマーク検出を実行

### 2.2 スタンプ生成

- 円形3分割の印鑑PNGをアプリ内で動的生成
- 構成（上から）
  - 上段：名前
  - 中段：日付（`'YY.MM.DD`形式、例：`'26.05.23`）
  - 下段：所属／役職
- 区切りは水平の細線
- 背景は完全透明（PNGアルファチャンネル）

### 2.3 スタンプ設定項目（UI入力）

| 項目 | 入力方式 | 備考 |
|------|---------|------|
| 名前 | テキスト入力 | 任意文字列 |
| 所属／役職 | テキスト入力 | 任意文字列 |
| 日付 | 読み取り専用表示 | **押印実行ボタン押下時の日付を使用**、UIでは現在日付を表示し続け日が変わったら自動更新、改ざん防止のため手動編集不可 |
| サイズ（直径） | 数値入力／スライダー | 単位：mm、初期値：15mm、範囲：5〜30mm |
| 線の太さ | 数値入力／スライダー | 単位：pt |
| 書体 | プルダウン | 同梱の Noto Sans JP のバリエーション |

### 2.4 マーク種別の選択

- 5種類のマークから1つを選択（ラジオボタン）
  - ◴ ◰ ⊗ ⊠ ☆
- 選択中のマーク種別のみが押印対象となる
- 切り替えると検出結果ペインがリアルタイムに更新される

### 2.5 マーク検出

PDFの種類に応じて自動切替。

```
各ページ
  │
  ├─ ステップ1：テキスト検索（PyMuPDF）
  │    └─ マーク文字が見つかれば座標取得して完了
  │
  └─ ステップ2：画像レンダリング＋テンプレートマッチング
       └─ ページを300dpi画像化、OpenCVで5種マークと照合
       └─ 一致度80%以上の座標を取得（PDF座標系に変換）
```

検出対象：
- 印刷されたマーク（Acrobat製・スキャンPDFいずれも対応）
- 手書きマークは対象外
- マークサイズは8pt〜36ptを想定

### 2.6 押印処理

選択中マーク種別が検出されたページに対して、各検出位置で以下を実行：

1. マーク矩形を **白い四角** で塗りつぶす（マーク領域＋余白2pt）
2. 押印実行ボタン押下時点の日付でスタンプPNGを生成（指定サイズ・色・書体）
3. スタンプ画像をPDFに `page.insert_image()` で合成
4. 配置：スタンプ中心が検出座標 (cx, cy) に一致するよう配置

### 2.7 出力

- **元PDFに上書き保存**
- バックアップは作成しない
- 押印実行前に確認ダイアログ：「PDFを上書きします。よろしいですか？」

### 2.8 ログ記録

| 項目 | 値 |
|------|-----|
| 形式 | CSV（UTF-8 BOM付き） |
| ファイル名 | `stamp_log.csv` |
| 保存場所 | `%USERPROFILE%\Documents\StampApp\stamp_log.csv` |
| 書き込み | 追記モード（既存ログ保持） |
| 1行 = 1回の押印実行 | 複数ページに押印した場合もまとめて1行 |

ログ列：

| 列名 | 例 |
|------|-----|
| timestamp | `2026-05-23 14:32:18` |
| pdf_path | `C:\Users\<ユーザー名>\Documents\契約書.pdf` |
| pages | `2,3,5,7,9` |
| stamp_name | `山田 太郎` |
| stamp_date | `'26.05.23` |
| stamp_affiliation | `営業部` |

初回起動時はヘッダ行付きで新規作成。フォルダも自動作成。

## 3. 非機能要件

- **OS**：Windows 10/11（64bit）
- **配布**：単一EXEファイル（インストール不要、ダブルクリック起動）
- **EXEサイズ**：約60〜100MB想定
- **動作環境**：Python本体のインストール不要（EXEに内蔵）
- **改ざん防止**：日付は押印実行時のシステム日付を強制使用、UI編集不可

## 4. 技術スタック

| 用途 | ライブラリ | バージョン目安 |
|------|-----------|---------------|
| GUI | customtkinter | 5.x |
| PDF操作 | PyMuPDF (fitz) | 1.24+ |
| 画像処理 | OpenCV (opencv-python-headless) | 4.x |
| 数値計算 | NumPy | 2.x |
| PNG生成 | Pillow | 11.x |
| EXE化 | PyInstaller | 6.x |

選定基準：GitHubスター1000以上、直近3か月以内に更新あり、サプライチェーン攻撃の懸念なし。

## 7. スタンプ色

- 朱色固定：`#C8102E`（RGB）
- 変更不可（v1スコープ外）

## 8. 動作フロー（押印実行時）

```
[押印実行ボタン押下]
  │
  ▼
確認ダイアログ「PDFを上書きします。よろしいですか？」
  │  Yes
  ▼
押印実行時点の日付でスタンプPNGを生成
  │
  ▼
各ページ（選択マークが検出されたページのみ）
  ├─ マーク矩形を白塗り
  └─ スタンプ画像をマーク中心に挿入
  │
  ▼
元PDFを上書き保存（fitz の doc.saveIncr() または save() 上書き）
  │
  ▼
CSVログに1行追記
  │
  ▼
完了通知「Nページに押印しました」
```

## 9. スコープ外（v1で実装しない）

- 複数PDFの一括処理
- 自動バックアップ
- スタンプ色変更
- 日付の手動指定
- 手書きマークの検出
- スタンプ位置の手動微調整
- スタンプ形状の変更（楕円、角印など）

## 10. リスクと注意点

| リスク | 対策 |
|--------|------|
| 上書き保存により元PDFが失われる | 押印実行前の確認ダイアログで明示 |
| スキャン画質が低くマーク検出失敗 | テンプレートマッチング閾値を調整可能に（v2以降） |
| マーク領域の白塗りで罫線が消える | スタンプが大きいため視覚的に隠れる前提。罫線への影響は受容 |
| 押印中にPCがスリープ・電源断 | PDFの破損可能性あり。バックアップは v1スコープ外のためユーザーが必要に応じて事前コピー |
